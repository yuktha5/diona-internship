# Exercise 1: WCB Medical & Travel Expense Request PDF Generator

Standalone web application for generating pixel-perfect, dynamic **Medical & Travel Expense Request** forms for the Workers Compensation Board of Manitoba.

## 📋 Features
- **6 Detailed Expense Tables**: Prescription Drugs, OTC Medicines, Medical Supplies, Parking, Mileage (with excess travel deduction), and Bus/Taxi with pre-approval flags.
- **Smart Pagination**: Automatically flows across multiple pages when rows are added.
- **AI OCR Receipt Extractor**: Automatically parses receipts and inserts expense rows.
- **One-Click PDF Export**: Direct native browser print (`Ctrl+P`) formatted for Letter PDF.

## 🚀 How to Run
- Double-click `index.html` or run `start.bat`.
- Or run `python -m http.server 8001` inside this folder.
