# Exercise 2: WCB Worker Progress Report (WP) PDF Generator

Standalone web application for generating pixel-perfect, dynamic **Worker Progress Report (WP)** 3-page forms for the Workers Compensation Board of Manitoba.

## 📋 Features
- **3-Page Report**: Return-to-Work duties, narrative progress, 1–10 interactive visual pain scale, treatment schedules, chiropractor/physio tracking, medication regimens, and legal certifications.
- **AI Clinical Summarizer**: Generates executive case summaries for WCB Case Adjudicators.
- **Webcam Video Check-in Recorder**: In-browser video recorder for physical mobility and rehab exercise updates.
- **One-Click PDF Export**: Direct native browser print (`Ctrl+P`) formatted for 3-page Letter PDF.

## 🚀 How to Run
- Double-click `index.html` or run `start.bat`.
- Or run `python -m http.server 8002` inside this folder.
